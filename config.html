Naming your traits

          
It stops on the first one that lands.

          

            
"Godly"that exact trait

            
"Godly Hexed"the hexed version of it

            
"All Mythic"any Mythic trait, plain only

            
"All Mythic Hexed"any hexed Mythic

            
"Any Hexed"any hexed trait at all

          

          
Wanted_Traits = { "All Mythic", "All Mythic Hexed" },

          
"All Mythic" does not include hexed Mythics. List both, as above, if you want either.

Three things that break it

          
Use the auto-execute folder. The farm teleports between the lobby and the tower, and only auto-execute re-runs the script after a teleport. Run it by hand and it stops at the first one.

          
Keep the config above the loadstring line. Below it, and it's ignored.

          
No window is normal. With a config, the hub runs hidden. Delete the whole Config block if you want the clickable hub back.


          
Two things that look broken but aren't

          
It skipped my stand. Every copy already has a trait you asked for. Rolling it would destroy the good trait you already have.

          
It stopped and named a typo. A name that matches nothing halts the script and tells you what you probably meant — better than guessing and rolling the wrong stand.


          
Picking what to farm

          
Stands_Swap_Priority = {
    { Stands = { "Standless" },                Wanted_Traits = { "Any Hexed" } },
    { Stands = { "The Vessel", "Kuro Claws" }, Wanted_Traits = { "Godly" } },
}

          
Each line is one group, farmed top to bottom. Several stands on one line share the same target traits.


          
Five ways to name a trait

          
It stops on the first one that lands.

          

            
"Any Hexed"any hexed trait

            
"All Mythic"any plain Mythic; also All Legendary and All Epic

            
"All Mythic Hexed"any hexed Mythic; also All Legendary Hexed

            
"Godly"that exact trait

            
"Godly Hexed"the hexed version of it

          

          
"All Mythic" and "All Mythic Hexed" are separate — the plain form never accepts a hexed roll. List both if you'll take either.

          
Capitals, spaces, and punctuation don't matter — "the vessel" works.

          
Ask for "Prime" and a hexed Prime is kept too — it's strictly better, so it's never rolled away.


          
Just want UCoins, not traits?

          
Leave Wanted_Traits empty and turn ascending off:

          
Stands_Swap_Priority = {
    { Stands = { "Standless" }, Wanted_Traits = { } },
},

Farming = { Auto_Ascend = false },

          
Empty traits means it never touches the roller — so it farms on your spec, normally skipped for being too good, and can't roll over a trait you wanted to keep. Auto_Ascend = false keeps the coins instead of spending them.


          
The other settings

          
Floor_Cap — clear this floor, then restart, 0 climbs forever.

          
ItemsToKeep — auto-sell clears everything else to stop your bag filling up. Anything named here is never sold and is stored automatically the moment it drops. A floor won't skip until it's safely stored.

          
Optimization — Fps_Cap caps your framerate, Eco_Mode drops graphics to the minimum. Both are worth it for an overnight farm.

          
Farming.Auto_Ascend — set false to keep your UCoins. Ascending spends them and resets your level.

          
Combat — Auto_Buso_Haki keeps Haki up, Auto_Skills casts your abilities. Skill_Keys = {} fires every key; name them like { "R", "T" } to pick. Charged keys use +, like "R+".

          
WebHook — Discord ping each time a trait is secured. Your username is spoilered.

          
Skins_Settings — recycles skins into points, forges points into unusuals, while you farm. Keep_Rarities is what you protect — everything else is melted. Valid: Rare, Epic, Legendary, Event, Mythic, Universal. Limited, Unobtainable, equipped, and locked skins are never touched.
